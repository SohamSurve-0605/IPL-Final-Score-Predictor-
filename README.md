# IPL-Final-Score-Predictor-
A Regression ML project predicting IPL final innings scores. Engineered live-match features (CRR, wickets, balls left) using a Scikit-Learn pipeline. Trained and compared Random Forest, Decision Tree, and XGBoost. Random Forest achieved the best MAE (4.51 runs) and R² (0.893). Features an interactive Streamlit UI.
